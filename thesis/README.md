# Bachelor's Thesis

This directory contains the complete bachelor's thesis associated with this project.

**Title:** [*Application of Machine Learning Techniques for Event Classification in ATLAS Open Data*](Pavlos_Panagiotopoulos_Bachelor_Thesis.pdf)

**Author:** Pavlos Panagiotopoulos  
**Institution:** National and Kapodistrian University of Athens  
**Department:** Department of Physics  
**Year:** 2026

The thesis is written in Greek. This GitHub repository provides an English overview of the analysis, methodology, and main results.

The thesis investigates the application of machine-learning techniques to signal-background classification in simulated ATLAS Open Data, focusing on the Higgs boson dimuon decay channel \(H \rightarrow \mu^+\mu^-\).
